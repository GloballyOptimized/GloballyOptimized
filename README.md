<table>

generates charts, graphs, and maps from PostgreSQL results.
`1,600+ queries/day · 92% accuracy`

</td>
<td width="50%" valign="top">

**Holmes AI — Image QC Pipeline**
Async pipeline on FastAPI + RabbitMQ processing 5,000+ support ticket images daily. S3 pull, YOLOv9

`1,260s → 7s — a 180× speedup`

</td>
</tr>
<tr>
<td width="50%" valign="top">

**Link — Fraud Detection**
Real-time fraud detection across a 21,000+ merchant network. RabbitMQ event ingestion, feature engineering
on transaction velocity and history, LightGBM classifier.
`100,000+ tx/day · 78% fewer LEA complaints`

</td>
<td width="50%" valign="top">

**vLLM Inference Stack**
Built from scratch — 96GB VRAM, tensor parallelism, 8-bit AWQ quantization, continuous batching behind an
async FastAPI gateway. 128K context window, hosted locally.
`50+ concurrent requests · 3,000+ tok/s · sub-3s p99`

</td>
</tr>

<td width="50%" valign="top">

</td>

deduplication and rate limiting.
`94%+ accuracy across 20,000+ records · $28K saved`
